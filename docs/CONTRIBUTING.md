# Contributing

Contributions are welcome. Whether you're reporting a problem, suggesting an idea, or submitting code, please take a moment to read this guide before contributing.

## Issues

Before opening an issue, check whether it has already been reported or discussed.

Use the provided issue forms when opening an issue and fill out all required fields. If you have additional information that isn't covered by the form, include it in the relevant field if one is available.

## Pull Requests

Before submitting a pull request, check existing issues and pull requests to avoid duplicate work.

We provide a pull request template with questions to help explain your changes and how you tested them. Please fill it out and provide any additional context that might be useful to reviewers.

For larger changes or new features, open an issue first to discuss the idea before implementing it.

Keep your changes focused and make sure they fit the project's existing code style and structure.

## AI Usage

AI tools are allowed, but contributions must be reviewed and understood before submission.

If you use AI, follow the [AI Usage Policy](/AI_POLICY.md).

## A Final Note

These projects are maintained by people in their free time. Please be respectful when opening issues, requesting features, or submitting pull requests.

Beginners are welcome. You don't need to be an expert to contribute, and asking questions is fine.

Thanks for taking the time to contribute.
